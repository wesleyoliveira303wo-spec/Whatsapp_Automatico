### CQRS (Command Query Responsibility Segregation)

- Use for high‑traffic read operations (e.g., lead search) separating read models from write models.
- Implement read side as Prisma queries with caching.

### Event Sourcing (Future)

- Consider for audit trail of campaign state changes.
- Store events in `analytics_events` table.

### Repository Pattern

- Abstract data access via repository interfaces in the Domain layer.
- Implement using Prisma within the Infrastructure layer.

### Service Layer

- All business logic lives in service classes under `src/backend/services/`.
- Services are injected into controllers via DI container.

### Observer Pattern

- Use Node EventEmitter for internal events (e.g., `campaignCompleted`).
- Allows decoupled listeners for analytics, notifications.

### Strategy Pattern for AI Prompts

- Different prompt strategies (greeting, qualification) implemented as separate classes.
- Swappable via configuration.
