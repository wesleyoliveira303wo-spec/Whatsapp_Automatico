# Idioma oficial
- **Português (Brasil)**

## Diretrizes
- Toda comunicação escrita (documentação, mensagens de commit, PRs, relatórios, análises) deve ser em Português.
- O inglês é permitido apenas para:
  - nomes de tecnologias (React, Prisma, Docker, Fastify, etc.)
  - palavras reservadas da linguagem de programação
  - trechos de código e comandos de terminal
  - nomes oficiais de APIs e bibliotecas
- Não traduzir nomes de classes, funções, variáveis ou bibliotecas.
