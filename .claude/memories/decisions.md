### 2026-07-01 – Adopt Clean Architecture
**Status**: Accepted
**Context**: Need clear separation for multi‑tenant SaaS.
**Decision**: Use Clean Architecture with layers (Presentation, Application, Domain, Infrastructure).
**Consequences**: Improves testability, enforces boundaries, slight boilerplate overhead.

### 2026-07-01 – Use TypeScript Strict Mode
**Status**: Accepted
**Context**: Complex data models across stack.
**Decision**: Enforce `strict` compiler options.
**Consequences**: Early error detection, enhances developer confidence.

### 2026-07-01 – Choose PostgreSQL + Prisma
**Status**: Accepted
**Context**: Need relational model with tenant isolation.
**Decision**: PostgreSQL with Prisma ORM.
**Consequences**: Strong typing, migrations, RLS for security.

### 2026-07-01 – Implement WhatsApp via Puppeteer QR
**Status**: Accepted (with migration path).
**Context**: No Cloud API access yet.
**Decision**: Puppeteer QR login, abstract via `IWhatsAppProvider`.
**Consequences**: Fast MVP, future swap to Cloud API.

### 2026-07-01 – AI Provider = Claude
**Status**: Accepted
**Context**: Anthropic alignment, existing internal expertise.
**Decision**: Claude API wrapper, prompt templates, token caching.
**Consequences**: Need cost monitoring, easy swap later.

### 2026-07-01 – Job Queue = BullMQ + Redis
**Status**: Accepted
**Context**: Need reliable background processing.
**Decision**: BullMQ on Redis for jobs.
**Consequences**: Requires Redis scaling, provides retries.
