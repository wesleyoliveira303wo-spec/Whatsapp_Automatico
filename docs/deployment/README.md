# Deployment Documentation

Guidelines for deploying the WhatsApp Automation Platform.

## Environments
- **Local**: Docker Compose (`docker-compose.yml`).
- **Staging / Production**: Kubernetes cluster using Helm chart (`helm/whatsapp-automation/`).

## Docker Compose
```yaml
version: '3.8'
services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
      POSTGRES_DB: whatsapp
    volumes:
      - pgdata:/var/lib/postgresql/data
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
  api:
    build: ./src/backend
    env_file: .env
    depends_on:
      - postgres
      - redis
  frontend:
    build: ./src/frontend
    env_file: .env
    ports:
      - "3000:3000"
volumes:
  pgdata:
```

## Helm Chart
- Install: `helm repo add myrepo https://example.com/charts && helm install whatsapp-automation myrepo/whatsapp-automation`
- Values file (`values.yaml`) configures image tags, replica count, secrets.
- CI/CD pipeline runs `helm upgrade --install` on every successful push to `main`.

## CI/CD
- GitHub Actions workflow (`.github/workflows/ci.yml`) builds Docker images, runs tests, pushes images, and triggers Helm upgrade.
- Secrets stored in GitHub Actions (`DOCKER_USERNAME`, `DOCKER_PASSWORD`, `KUBE_CONFIG`).
