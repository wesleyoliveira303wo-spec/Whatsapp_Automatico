# Frontend Documentation

This folder contains documentation specific to the **frontend** (Next.js) part of the project.

- **Components** – design guidelines, usage examples, and shadcn/ui customizations.
- **Pages** – routing strategy, SSR considerations, and data fetching patterns.
- **Hooks** – shared React hooks and best practices.
- **Performance** – React profiling, bundle analysis, and lazy loading.

All markdown files should be linked from the top‑level `README.md` if they are part of the public docs.
