# Diagrams

This folder stores architecture diagrams, flowcharts, and component visuals.

- `system-context.mmd` – high level system context diagram.
- `component-diagram.mmd` – detailed component interaction diagram.
- `database-erd.mmd` – ER diagram of the PostgreSQL schema.

Diagrams are authored in **Mermaid** (`.mmd`) and can be rendered via VS Code extensions or the online Mermaid Live Editor.
