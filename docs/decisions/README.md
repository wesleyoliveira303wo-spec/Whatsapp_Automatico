# Decision Records

This folder mirrors the `DECISIONS.md` log but stores individual markdown files for each architectural decision. Each file follows the template:

```markdown
# Decision: <Title>

**Date**: YYYY-MM-DD
**Status**: Accepted / Superseded / Deprecated
**Context**: ...
**Decision**: ...
**Consequences**: ...
```

Links to these files are added to `DECISIONS.md` for easy navigation.
