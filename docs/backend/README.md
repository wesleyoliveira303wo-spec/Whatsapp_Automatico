# Backend Documentation

Documentation for the **backend** (Node.js/Express) services.

- **API Layer**: REST/GraphQL endpoints, request validation, OpenAPI spec.
- **Services**: Business logic for leads, campaigns, AI integration, WhatsApp connectivity.
- **Infrastructure**: Prisma models, BullMQ job definitions, Redis configuration.
- **Security**: Auth middleware, RBAC, input sanitisation.
- **Observability**: OpenTelemetry instrumentation, Winston logging.

Refer to `ARCHITECTURE.md` for the high‑level view.
