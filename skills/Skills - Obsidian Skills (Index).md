## Principios do Sistema

1. **Wikilinks para tudo interno** -- [[Nota]] para notas, [texto](url) para externas
2. **Frontmatter com propriedades** -- metadados YAML no topo de cada nota
3. **Embed para incorporar** -- ![[Nota]] traz conteudo de outra nota
4. **Callouts para destacar** -- > [!note] para informacoes importantes
5. **Tags para categorizar** -- #tag, #aninhada/tag
6. **JSON Canvas para visuais** -- mapas mentais, fluxogramas
7. **Bases para dados** -- views filtradas e calculadas
8. **CLI para automacao** -- scripts e operacoes programaticas
9. **Defuddle para web** -- extracao limpa de conteudo web
