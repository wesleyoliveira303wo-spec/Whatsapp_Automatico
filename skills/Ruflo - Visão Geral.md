# Ruflo — Visão Geral

**Ruflo** (anteriormente Claude Flow) é um **meta-harness para agentes de IA** — uma camada de execução em torno do Claude Code e OpenAI Codex que adiciona 100+ agentes especializados, coordenação em enxame (swarm), memória auto-aprendizável, comunicação federada entre máquinas e guardrails de segurança empresarial.

> **Agente = Modelo + Harness.** O modelo escreve; o harness dá ferramentas, memória, loops, sandboxes e controles. Ruflo é o harness.
