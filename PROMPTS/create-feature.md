## 2. Instructions for Claude

1. **Analyze the request**. Identify the functional scope, impacted layers (frontend, backend, DB), and any new data models.
2. **Propose a plan** following the "EnterPlanMode" workflow:
   - List files to modify/create.
   - Outline the steps (e.g., add Prisma model, generate service, UI page, tests).
   - Highlight any architectural trade‑offs.
3. **Ask clarification** if any requirement is ambiguous.
4. **Once approved**, generate the implementation:
   - Write code files using the **Edit** tool when updating existing files, **Write** for new ones.
   - Ensure naming conventions, linting, and tests.
   - Update documentation (`API_SPECIFICATION.md` if new endpoints are added).
5. **Run tests** (`npm test`) and ensure 80% coverage.
6. **Commit** the changes with a Conventional Commit message, e.g., `feat: add lead import CSV endpoint`.
7. **Create a PR** using the GitHub template; include a short summary and link to the relevant design document.
