**Purpose**: Standardize the process for fixing bugs using Claude as an assistant.

## 2. Steps for Claude
1. **Locate the defect**:
   - Use the description provided by the user to search the codebase (Glob/Grep).
   - Identify the exact file and line (`[file.ts:42]`).
2. **Propose a minimal fix**:
   - Explain the root cause in one sentence.
   - Suggest the precise code change.
3. **Ask for confirmation** if the fix touches multiple modules or could have side effects.
4. **Apply the change** using the **Edit** tool (or **Write** for new file).
5. **Add or update tests** covering the bug scenario.
6. **Run the test suite**; ensure no regression.
7. **Commit** with a Conventional Commit: `fix: <short description>`.
8. **Create PR** using the PR template.
