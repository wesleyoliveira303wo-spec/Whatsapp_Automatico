# WhatsApp Automation Platform

A smart, AI‑powered CRM for WhatsApp prospecting, lead management, automated outreach, and analytics. Designed as a modular monorepo with a clean architecture, ready to evolve into a multi‑tenant SaaS.

## Quick Start

1. **Clone the repo**
   ```bash
   git clone <repo-url>
   cd Whatsapp-automatico
   ```
2. **Install dependencies**
   ```bash
   npm ci
   ```
3. **Set up environment**
   Copy `.env.example` to `.env` and fill the required values.
4. **Run the development stack**
   ```bash
   docker compose up -d   # starts Postgres, Redis
   npm run dev               # starts Next.js frontend & API server
   ```
5. **Open** `http://localhost:3000` in your browser.
